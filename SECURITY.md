# Security policy

SilhouetteAI is a privacy boundary, so reports about prompts bypassing inspection,
incorrect redaction, token-map exposure, or unexpected network activity are treated
as security issues.

Please do not include real personal information, credentials, or private prompts in
a report. Use synthetic examples and open a private GitHub security advisory for
sensitive findings. For ordinary bugs, use the public issue tracker.

Only the latest release receives security fixes. Until a Chrome Web Store build is
published, releases are distributed as source and loaded unpacked.
